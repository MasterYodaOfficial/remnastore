# RemnaStore 1.0.2

## Срочное исправление оплаты

- Исправлена ошибка PostgreSQL при создании записи о выдаче или продлении
  подписки: время создания сохраняется в UTC без часового пояса, как требует
  существующее поле БД. В версии 1.0.1 успешная оплата могла оставаться
  в ожидании, а подписка не продлевалась из-за отката транзакции.
- В CI добавлен PostgreSQL 17 и регрессионный тест записи продления
  через asyncpg. SQLite не выявляла несовместимость типов времени.

## Обновление

Миграции БД и новые переменные окружения на сервере не требуются.
Обновите API и worker-сервисы одним выпуском.

При закреплённой версии задайте `REMNASTORE_VERSION=1.0.2`; при `latest`
оставьте текущее значение. Индивидуальные `*_IMAGE_TAG` имеют приоритет.

```bash
docker compose pull && docker compose up -d --wait
```

Уже оплаченные, но не применённые покупки нужно проверить по статусу ЮKassa
и повторно обработать существующий платёж. Если срок ожидания истёк,
одного обновления контейнеров может быть недостаточно для восстановления.
Повторно оплачивать такую покупку не нужно.
