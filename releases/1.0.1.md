# RemnaStore 1.0.1

## Исправления

- Шкала подписки показывает остаток всего непрерывного периода и пересчитывается
  при продлении. Добавлена дата окончания; для подписок без полной истории
  покупок отображаются дни и дата без недостоверного процента.
- Устройства в личном кабинете загружаются при ответах панели с `userId`
  вместо `userUuid`. Исправлены чтение списка, удаление устройства и сброс всех
  устройств без ошибки разбора успешного ответа Remnawave.
- Незавершённый платёж создаёт одно уведомление, даже если после истечения
  времени провайдер прислал отмену. Исправление учитывает уведомления,
  созданные предыдущей версией. Отправка в Telegram защищена от одновременной
  обработки одной доставки несколькими worker-процессами.
- Двойное быстрое нажатие при оплате больше не создаёт два платежа.
- Сообщение о собственной реферальной ссылке показывается один раз для этого
  аккаунта и кода. Повторный вход не активирует отклонённую ссылку заново;
  переход по другой реферальной ссылке продолжает работать.

## Зависимости

- Python SDK Remnawave обновлён до `2.8.0`; обработка HWID адаптирована отдельно,
  поскольку в SDK остаётся несовместимая модель ответа устройств.
- Обновлены зависимости API, бота, кабинета и админки с исправлениями безопасности.
  Особенности совместимости описаны в `docs/dependencies.md` репозитория.

## Обновление

Новых переменных окружения и миграций БД в этом выпуске нет.

В `.env` используйте `REMNASTORE_VERSION=latest` или закрепите `1.0.1`.
Индивидуальные `API_IMAGE_TAG`, `BOT_IMAGE_TAG`, `WEB_IMAGE_TAG`, `ADMIN_IMAGE_TAG`
имеют приоритет над общей версией.

```bash
curl -fsSL -o compose.yml https://github.com/MasterYodaOfficial/remnastore/releases/download/v1.0.1/compose.yml
docker compose pull && docker compose up -d --wait
```

Действующий `.env` сохраняется. Обновляйте API, worker-сервисы и интерфейсы
одним выпуском. Перед обновлением сохраните резервную копию БД.
