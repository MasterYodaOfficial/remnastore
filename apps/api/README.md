# API

`apps/api` — backend проекта на `FastAPI`.

Отвечает за:

- аккаунты и авторизацию
- баланс, рефералов и выводы
- платежи и webhook
- подписки и интеграцию с `Remnawave`
- bootstrap для `web` и `admin`

Основной docker-сервис: `api`  
Health endpoint: `GET /api/v1/health`

Тарифы хранятся в таблице `subscription_plans`. Раздел тарифов в админке сохраняет
название, цены в рублях и Stars, срок, преимущества, лимит устройств и признак
популярного тарифа непосредственно в БД. Кабинет, бот, оплаты и промокоды читают
этот же каталог; перезапуск после изменения тарифа не требуется.

Миграция `20261019_subscription_plans` один раз переносит прежний каталог из
`app/config/subscription-plans.json`, сохраняя порядок и все параметры. После
миграции приложение больше не читает и не изменяет этот файл. Он остаётся только
источником начальных данных для установки и перехода со старой версии.

В Docker миграция выполняется автоматически при старте API. Если тарифы меняли
внутри старого контейнера, перед обновлением сохраните каталог и выполните перенос
по [инструкции](../../docs/deploy-vds.md#переход-на-хранение-тарифов-в-бд).
